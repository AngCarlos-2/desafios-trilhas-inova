# desafios-trilhas-inova
Desafios do Programa Trilhas Inova 2B.

# Desafio 3

1. O projeto demonstra um formulário de inscrição, no qual o usuário deve preencher as informações corretamente para realizar a inscrição.
2. Para rodar localmente, é necessário executar o arquivo HTML principal da aplicação, que corresponde a tela de cadastro do usuário.
3. Tecnologias utilizadas: HTML, CSS e JavaScript (JS).
4. Preenchimento de informações, salvamento de informações e criação de um novo usuário.
